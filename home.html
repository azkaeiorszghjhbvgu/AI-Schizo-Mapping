Romania Map Pathfinding

Blind Search vs. Heuristic Search, visualized side by side

What is this?

This app solves the classic Romania map pathfinding problem from AI search theory: given a start city and a goal city, find a route between them on a weighted road-distance graph. It runs two search algorithms side by side so you can see how a blind (uninformed) search compares to a heuristic (informed) search on the same problem.

Blind Search

Uniform-Cost Search (Dijkstra's algorithm)

Expands nodes purely by accumulated path cost from the start, with no knowledge of where the goal is.

Heuristic Search

A* Search

Expands nodes using path cost plus a straight-line-distance estimate to the goal, guiding the search more directly.

What you'll see

  • Two live maps animating each algorithm's node expansion
  • The final path highlighted on each map
  • A comparison table of path cost, nodes expanded, max frontier size (space), and runtime

Pick any start and goal city, choose an algorithm (or compare both), and run the search.
